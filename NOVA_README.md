# Nova Launcher — кастомный лаунчер на ядре Modrinth (Theseus)

Rust-ядро (`apps/app`, `packages/app-lib`) **не изменено** — авторизация Microsoft, инстансы и запуск игры
выполняет Theseus. Полностью заменён фронтенд: `apps/app-frontend` (Vue 3 + Vite, без Tailwind/UI-китов Modrinth).

## Как получить exe
**Вариант A — GitHub Actions (проще всего, ничего ставить не нужно)**
1. Создайте репозиторий на GitHub и загрузите туда содержимое этой папки.
2. Вкладка **Actions → Build Nova Launcher (Windows exe) → Run workflow**.
3. Через ~20–40 мин (первая сборка Rust) скачайте артефакт `Nova-Launcher-windows`:
   `Nova Launcher.exe` (портативный) и установщик NSIS.

**Вариант B — локально на Windows:** установите Node 24+, pnpm, Rust, VS Build Tools (C++) и запустите `./build-windows.ps1`.

## Общие сборки и аккаунт с Modrinth App
Идентификатор приложения оставлен `ModrinthApp`, поэтому лаунчер читает ту же папку данных
(`%APPDATA%\ModrinthApp`): сборки и вход в аккаунт подхватываются автоматически.
Не запускайте Nova Launcher и оригинальный Modrinth App одновременно (общая база данных; single-instance
защита может просто сфокусировать уже открытое окно оригинала).

## Темы
12 встроенных тем + свои: цвета, шрифты, скругления, стиль карточек/кнопок, hover-эффекты, скорость анимаций,
размытие, свечение, зернистость, фон (градиент/картинка), произвольный CSS. Импорт/экспорт JSON.
Формат темы — `apps/app-frontend/src/themes/types.ts`; встроенные — `themes/builtin.ts`.

## Возможности интерфейса
- Библиотека: поиск, фильтры, избранное, статусы, запуск/остановка.
- Создание сборок: Vanilla/Fabric/Forge/NeoForge/Quilt, выбор версии игры и загрузчика, импорт .mrpack.
- Страница сборки: переименование, копия, удаление, восстановление файлов, список модов/ресурспаков/шейдеров/датапаков (вкл/выкл, обновление, удаление, добавление своих файлов).
- Каталог Modrinth: поиск модов, модпаков, ресурспаков, шейдеров, датапаков; установка с зависимостями.
- Все операции выполняет ядро Theseus.
